# Cara Menghapus Cache Browser untuk Melihat Favicon Baru

Favicon website sudah diganti dari **bola bowling** menjadi **logo klinik** (lingkaran pink dengan siluet wanita), tetapi browser masih menyimpan icon lama di cache.

## Mengapa Favicon Masih Icon Lama?

Browser menyimpan favicon di cache untuk mempercepat loading. Karena itu, meskipun favicon sudah diganti di server, browser masih menampilkan icon lama yang tersimpan.

---

## 📱 Cara Clear Cache di MOBILE

### **Android Chrome**

1. Buka **Chrome** di HP Android
2. Ketuk **⋮** (titik tiga) di pojok kanan atas
3. Pilih **History** (Riwayat)
4. Ketuk **Clear browsing data** (Hapus data penjelajahan)
5. Pilih **Time range**: **All time** (Semua waktu)
6. Centang:
   - ✅ **Cookies and site data**
   - ✅ **Cached images and files**
7. Ketuk **Clear data**
8. Tutup Chrome sepenuhnya (swipe dari recent apps)
9. Buka Chrome lagi dan kunjungi https://klinik.drwskincare.com

### **iPhone Safari**

1. Buka **Settings** (Pengaturan) di iPhone
2. Scroll ke bawah, pilih **Safari**
3. Scroll ke bawah, ketuk **Clear History and Website Data**
4. Konfirmasi dengan ketuk **Clear History and Data**
5. Tutup Safari sepenuhnya (swipe up dari app switcher)
6. Buka Safari lagi dan kunjungi https://klinik.drwskincare.com

### **iPhone Chrome**

1. Buka **Chrome** di iPhone
2. Ketuk **⋯** (titik tiga) di pojok kanan bawah
3. Pilih **History**
4. Ketuk **Clear Browsing Data**
5. Pilih **Time Range**: **All Time**
6. Centang:
   - ✅ **Cookies, Site Data**
   - ✅ **Cached Images and Files**
7. Ketuk **Clear Browsing Data**
8. Tutup Chrome sepenuhnya
9. Buka Chrome lagi dan kunjungi https://klinik.drwskincare.com

## 💻 Cara Clear Cache di DESKTOP/LAPTOP

### **Google Chrome (Windows/Mac/Linux)**

**Cara Cepat:**
1. Buka https://klinik.drwskincare.com
2. Tekan **Ctrl + Shift + Delete** (Windows/Linux) atau **Cmd + Shift + Delete** (Mac)
3. Pilih **Time range**: **All time**
4. Centang:
   - ✅ **Cookies and other site data**
   - ✅ **Cached images and files**
5. Klik **Clear data**
6. Refresh halaman dengan **Ctrl + F5** (Windows/Linux) atau **Cmd + Shift + R** (Mac)

**Cara Manual:**
1. Klik **⋮** (titik tiga) di pojok kanan atas
2. Pilih **Settings** (Pengaturan)
3. Klik **Privacy and security** di sidebar kiri
4. Klik **Clear browsing data**
5. Tab **Advanced**, pilih **All time**
6. Centang semua, terutama **Cached images and files**
7. Klik **Clear data**

### **Mozilla Firefox (Windows/Mac/Linux)**

1. Tekan **Ctrl + Shift + Delete** (Windows/Linux) atau **Cmd + Shift + Delete** (Mac)
2. Pilih **Time range to clear**: **Everything**
3. Centang:
   - ✅ **Cookies**
   - ✅ **Cache**
4. Klik **Clear Now**
5. Refresh halaman dengan **Ctrl + F5** (Windows/Linux) atau **Cmd + Shift + R** (Mac)

### **Microsoft Edge**

1. Tekan **Ctrl + Shift + Delete**
2. Pilih **Time range**: **All time**
3. Centang:
   - ✅ **Cookies and other site data**
   - ✅ **Cached images and files**
4. Klik **Clear now**
5. Refresh halaman dengan **Ctrl + F5**

### **Safari (Mac)**

1. Buka **Safari**
2. Menu **Safari** → **Preferences** (atau **Settings** di macOS Ventura+)
3. Tab **Privacy**
4. Klik **Manage Website Data**
5. Cari **drwskincare.com**
6. Klik **Remove** atau **Remove All**
7. Klik **Done**
8. Tutup dan buka Safari lagi
9. Kunjungi https://klinik.drwskincare.com

## 🔄 Hard Refresh (Paksa Reload)

Jika masih belum berubah setelah clear cache, coba **Hard Refresh**:

- **Windows Chrome/Firefox/Edge**: `Ctrl + F5` atau `Ctrl + Shift + R`
- **Mac Chrome/Firefox/Safari**: `Cmd + Shift + R`
- **Mac Safari (alternatif)**: `Option + Cmd + E` (clear cache) lalu `Cmd + R`

---

## ✅ Verifikasi Favicon Sudah Berubah

Setelah clear cache, favicon yang benar adalah:

- ✅ **Logo Klinik**: Lingkaran pink dengan siluet wanita (bukan bola bowling)
- ✅ Terlihat di tab browser
- ✅ Terlihat di bookmark
- ✅ Terlihat di home screen (jika add to home screen)

---

## 🆘 Jika Masih Belum Berubah

Jika setelah clear cache masih menampilkan bola bowling:

1. **Tutup browser sepenuhnya** (close all tabs and windows)
2. **Restart browser**
3. **Buka Incognito/Private mode** untuk test:
   - Chrome: `Ctrl + Shift + N` (Windows) atau `Cmd + Shift + N` (Mac)
   - Firefox: `Ctrl + Shift + P` (Windows) atau `Cmd + Shift + P` (Mac)
   - Safari: `Cmd + Shift + N` (Mac)
4. Kunjungi https://klinik.drwskincare.com di incognito mode
5. Jika di incognito sudah benar, berarti cache normal mode masih tersimpan
6. Ulangi clear cache dengan **All time** dan pastikan centang **Cached images and files**

---

## 📝 Catatan Penting

- Favicon browser di-cache sangat agresif (bisa sampai berbulan-bulan)
- Clear cache akan menghapus password tersimpan dan login session di semua website
- Setelah clear cache, Anda perlu login ulang ke semua website
- Incognito/Private mode selalu menampilkan favicon terbaru karena tidak menggunakan cache
